# Numerical Methods Calculator

A comprehensive, interactive Python command-line tool for solving various numerical analysis problems. This script combines root-finding, interpolation, regression, and calculus methods into a single, easy-to-use menu.

## Features

This calculator includes 10 standard numerical methods:

**Root Finding Methods:**
1. Bisection Method
2. Secant Method
3. Modified Secant Method
4. Newton-Raphson Method
5. Fixed Point Iteration

**Interpolation & Regression:**
6. Lagrange Interpolation
7. Newton Divided Difference
8. Linear Regression

**Calculus:**
9. Numerical Integration (Midpoint, Trapezoidal, Simpson's - Simple & Composite)
10. Numerical Differentiation (Forward & Backward)

## Prerequisites

To run this script, you need Python installed on your machine along with the `sympy` library (which is used for scanning and differentiating mathematical functions).

You can install the required library using pip:
